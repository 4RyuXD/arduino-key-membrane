# arduino-key-membrane
Calculator with LCD Screen and 4X4 Keypad Membrane

### Components
Arduino Mega 2560 Microcontroller
4X4 Number Membrane Keypad
LCD1602 Module
10kOhm Potentiometer
220Ohm Resistor
Jumper Wires
Breadboard

### Libraries
Keypad by Mark Stanley, Alexander Brevig
LiquidCrystal by Arduino, Adafruit
